## 2. 총평

이번 lab01 모의해킹에서는 초기 로그인 정보 미변경, 취약한 phpMyAdmin 버전 사용, 평문 계정정보 노출, 추가 인증 없는 관리자 권한 전환이 확인되었다. 각 취약점의 연계로 웹 관리 페이지 접근을 시작으로 www-data 권한의 셸 확보, 일반 사용자 계정 접근, 최종 root 권한 획득까지 이어졌다. 이는 외부에서 시작된 침해가 서버 전체에 대한 통제권 확보로 확대될 수 있음을 보여준다.

보완을 위해 phpMyAdmin을 보안 패치가 적용된 지원 버전으로 업데이트하고, 관리 페이지의 접근 범위를 제한해야 한다. 초기 비밀번호와 노출된 계정 비밀번호는 변경하고, 평문 인증정보 파일을 제거하며 파일 접근 권한을 재점검해야 한다. 또한 sudo -i에 인증 요구 설정이 필요하고 업무에 필요한 명령만 허용하도록 최소 권한 원칙을 적용해야 한다.

### 6.1 phpmyadmin 로그인 초기값 변경 없이 사용 

  **6.1.1 설명**

 - phpmyadmin 로그인 페이지에 초기 정보값으로 로그인이 가능했다.

 - 초기 로그인 정보를 사용하면 공격자가 phpmyadmin에 쉽게 접속해 DB 열람, 변조, 삭제가 가능하다.

  **6.1.2 조치방법**

- 로그인 정보를 쉽게 유추할 수 없는 값으로 변경.

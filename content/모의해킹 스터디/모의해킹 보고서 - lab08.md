본 보고서는 2026년 10월 22일에 진행된 lab08에 대한 모의 해킹 보고서이다.

## 2. 총평

이번 lab08 모의해킹에서는 웹 페이지에 사용자 계정과 비밀번호 노출로 인한 RDP 접속, 이름에 공백이 있고 따옴표로 감싸지 않은 서비스 실행 경로의 취약점의 연계로 Administrator 그룹에 일반 사용자 계정을 추가할 수 있었다. 이는 외부에서 시작된 침해가 서버 전체에 대한 통제권 확보로 확대될 수 있음을 보여준다.

보완을 위해 웹 페이지에 노출된 계정 정보들을 삭제하고 서비스 이름과 실행 경로를 `sc.exe config`로 수정을 해야 한다.

### 6.1 웹 페이지에 사용자 계정과 비밀번호 노출

  **6.1.1 설명**

- 웹 페이지 화면과 개발자 도구 페이지에 계정 이름과 비밀번호가 노출되어 있었다.
- RDP 접속을 쉽게 성공했다.

  **6.1.2 조치방법**

- 웹 페이지에 노출된 정보를 삭제한다.

### 6.2 서비스 이름에 공백이 있고 따옴표로 감싸지 않은 서비스 실행 경로

  **6.2.1 설명**

- 서비스 이름에 공백이 있고 (`Disk Pulse Enterprise`) 서비스 실행 경로에 따옴표가 없다.
- Windiows가 공백을 기준으로 경로를 잘못 해석해서 다른 파일을 실행한다.

  **6.2.2 조치방법**

- 서비스 이름 혹은 서비스 실행 경로를 `sc.exe config`로 수정한다.

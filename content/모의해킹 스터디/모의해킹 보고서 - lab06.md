## 2. 총평

이번 lab06 모의해킹에서는 위조된 php로 업로드 정책 우회, 다른 사용자 그룹에게 권한이 있는 사용자 폴더, 비밀번호 없이 모든 사용자에게 실행 권한이 있는 Perl의 취약점 연계로 root 권한 탈취가 가능했다. 이는 외부에서 시작된 침해가 서버 전체에 대한 통제권 확보로 확대될 수 있음을 보여준다.

보완을 위해 업로드 디렉토리에서 php 실행을 차단하고 pdf 구조를 확실히 검증, 폴더의 접근 권한을 엄격히 설정, 비밀번호 인증을 추가하고 현재 실행하는 사용자의 권한만 쓸 수 있도록 제한하여야 한다.

### 6.1 위조된 php로 업로드 정책 우회

  **6.1.1 설명**

- pdf로 위조된 php로 업로드 정책을 우회했다.
- `webshell.php`를 pdf인 척 업로드해 웹쉘 공격이 가능했다.

  **6.1.2 조치방법**

- 업로드 디렉토리에서 php 실행을 차단한다.
- 허용 확장자를 엄격히 검사하고 매직 넘버만으로 판단하지 않도록 pdf 구조를 확실히 검증한다.

### 6.2 다른 사용자 그룹에게 권한이 있는 사용자 폴더

  **6.2.1 설명**

- `msrobot`폴더에 `www-data` 그룹이 접근이 가능했다.
- `msrobot`의 bash history를 읽어 `mrrobot`의 비밀번호가 노출 됐다.

  **6.2.2 조치방법**

- 폴더의 접근 권한을 엄격히 설정한다.

### 6.3 비밀번호 없이 모든 사용자에게 실행 권한이 있는 Perl

  **6.3.1 설명**

- `Perl`이 비밀번호 없이 모든 사용자가 사용이 가능했다.
- `sudo`로 `root`의 쉘을 실행해 권한을 탈취할 수 있었다.

  **6.3.2 조치방법**

- 비밀번호 인증을 추가하고 현재 실행하는 사용자의 권한만 쓸 수 있도록 제한한다.
